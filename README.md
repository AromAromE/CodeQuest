# 🎮 CodeQuest — The Dopamine RPG Coding Platform

> Transform your software development routine into an addictive video game experience.

---

## 🌟 Key Features

- 🧬 **Developer Evolution System**: Your avatar physically evolves from *Beginner Hacker* (Lv 1) to *Legendary Digital Architect* (Lv 100+).
- 🔊 **Zero-Dependency Web Audio Synth**: Instant low-latency arcade SFX for clicks, XP gains, coin pickups, combo streaks, boss hits, and level-up fanfare.
- ⚡ **Dopamine Feedback Engine**: Dynamic floating numbers (`+200 XP`, `+100 Coins`), Canvas particle glow, screen shake, and confetti celebration overlays.
- ⚔️ **Project & Task RPG Hub**: Track coding milestones with difficulty tiers (*Easy*, *Medium*, *Hard*, *Boss*) and combo multiplier decay bars.
- 🐉 **Weekly Raid Boss Arena**: Deal critical damage to colossal legacy bosses with every completed coding task.
- 🐾 **Virtual Pets & Coding Garden**: Grow cyber trees in your digital garden and keep virtual companions happy with daily coding streaks.
- 🌳 **RPG Skill Tree**: Visual mastery progression for Backend, Frontend, DevOps, Cloud, Database, and AI.

---

## 🚀 Quick Start

### 1. Run with Docker Compose
```bash
docker-compose up --build
```
- **Frontend**: http://localhost:3000
- **Backend API**: http://localhost:8080

### 2. Run Manually (Local Development)

#### Frontend (Next.js 15)
```bash
cd frontend
npm install
npm run dev
```

#### Backend (Go Gin)
```bash
cd backend
go run cmd/api/main.go
```
